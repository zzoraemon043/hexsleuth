# Responsible use

hexsleuth is a general analysis tool, in the same category as hex editors and format description languages.

## What it does not do

- It does not decrypt data, recover keys or bypass copy protection or other technical protection measures. When a region looks encrypted, hexsleuth reports that and stops.
- It does not ship sample files, keys or parsers for proprietary formats.

## What you are responsible for

- Analyze only files that you created or that you have the right to analyze.
- Follow the license terms of the software or content that produced the files.
- Do not publish copyrighted content that you extract with the help of this tool.

## Examples and tests in this repository

Examples, fixtures and tests use only open formats, such as PNG, ZIP, WAV and glTF, or formats designed for this repository. Contributions that add proprietary samples, keys or format parsers for commercial products will not be accepted.
